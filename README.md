# Converter by Yaza (Unicode Converter)

An advanced 1-Click Adobe Illustrator CEP Extension & JSX Script that flawlessly converts legacy **Bijoy (SutonnyMJ ANSI)** Bengali text into pure, modern **Bornomala Unicode**, eliminating broken ligatures, dotted circles, typist typos, and cross-platform font rendering issues.

Developed with ❤️ by **[Yahia Bin Zaman](https://github.com/yahiabinzaman)**

---

## ⚡ Key Features

- **Native Adobe Dark Theme UI**: Clean, professional Illustrator panel matching native Adobe aesthetics.
- **Smart Auto-Detect Engine**: Seamlessly supports ANSI V1 (Classic SutonnyMJ), ANSI V2 (Bijoy 52), ANSI V3 (Lipighor/Okkhor), and AI Refinement.
- **Auto-Refinement & Orthography Engine**:
  - Automatically eliminates all dotted circles (`◌`).
  - Auto-fixes quote & apostrophe transpositions in loan words (e.g., `কা’বা`, `কা’বায়`, `দু’আ`).
  - Resolves unmapped ANSI macron ligatures (`অবস্থায়`, `স্ব-চক্ষে`, `স্বজন`, `স্নান`, `স্মরণ`, `স্তব্ধ`, `অস্ত্র`).
  - Resolves broken Ma-ligatures (`গম্বুজ`, `অবলম্বন`, `লম্বা`, `কম্বল`, `দম্ভ`, `সম্বল`).
  - Fixes typist hyphen/caret errors in ligatures (`নিম্ন`, `নিম্নলিখিত`, `নিম্নোক্ত`, `চুম্বন`, `মাথা মুড়িয়ে`).
  - Enforces Bangla Academy spelling standards (`তৈরি`, `বেশি`, `শ্রেণি`, `ধরন`, `পদ্ধতি`, `সারণি`, `তালিকাভুক্ত`, `অন্তর্ভুক্ত`, `উপলক্ষে`, `ইতোমধ্যে`).
- **Flexible Scope Control**: Convert only selected text frames or all 400+ pages / artboards in one click.
- **Target Font Application**: Automatically applies Bornomala Regular / Bornomala Bold Unicode or keeps current font.

## 🚀 1-Click Installation

### Windows Installation
1. Download or clone this repository.
2. Double-click **`Install_Windows.bat`**.
3. Restart Adobe Illustrator and open:
   > **Window** > **Extensions** > **Converter by Yaza**

### macOS Installation
1. Download or clone this repository.
2. Double-click **`Install_Mac.command`**.
3. Restart Adobe Illustrator and open:
   > **Window** > **Extensions** > **Converter by Yaza**
